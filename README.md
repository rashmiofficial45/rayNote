# ⚡ rayNote (NoteFast)

A minimal, always-on-top, hyper-fast note-taking app for macOS, inspired by Raycast Notes. Built with **Tauri v2**, **Rust**, **React 19**, **TypeScript**, **TipTap v3**, and **SQLite FTS5**.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ & `pnpm`
- Rust 2021 toolchain (`cargo`, `rustc`)
- macOS 10.15+ (Apple Silicon or Intel)

### Development
```bash
# Install dependencies
pnpm install

# Run desktop app in development mode
pnpm tauri dev
```

### Production Build
```bash
pnpm tauri build
```
